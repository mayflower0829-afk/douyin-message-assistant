# 抖音消息助手 · macOS

原生 Swift / AppKit 桌面工具：选择已加载的会话、自定义单行消息、调节发送间隔。没有 Python、浏览器驱动或云端服务依赖。退出 Codex 不影响应用运行。

## 当前可用功能

- 刷新抖音已加载的会话，下拉选择收件人；同名重复条目拒绝自动发送。
- 自定义中文、英文或表情，支持单行文字。
- 间隔最低 0.1 秒，可手填 0.3、0.5、0.8 等中间速率。默认 0.5 秒。
- 0.1 / 0.2 / 0.5 / 1 秒快捷档位。每次 1–100000 次，默认 1 次。
- 开始、停止和设置保存。切换应用、会话或输入框会停止发送。
- 等待输入框清空再继续，5秒仍未清空则停止。检测到发送失败或平台限制时停止，不盲重发或绕过平台限制。

目标速率不代表消息送达速率；界面计数不证明对方收到。抖音需保持前台、电脑保持唤醒，不能在应用退出或电脑关机后继续发送。

## 构建与使用

要求 macOS 14+、Xcode Command Line Tools、已登录的抖音桌面客户端。

```sh
./scripts/test.sh
./scripts/build.sh
open dist/抖音消息助手.app
```

首次使用：点击“授权辅助功能”，在系统设置中允许此应用。先在抖音打开消息面板，再刷新、选择会话、编辑消息、设置间隔和次数，最后点击“开始”。

新应用或构建的签名变化时，macOS可能要求移除旧辅助功能条目，再重新添加应用。构建使用本地ad-hoc签名，并非Apple Developer ID签名或公证。

本机设置保存在应用偏好中，不提交到仓库。不上传Cookie、登录凭证或聊天记录。切换抖音账号后，请重新核对所选会话；仅凭昵称不能识别同名账户。
