# 抖音消息助手 · macOS

原生 Swift / AppKit 桌面工具：选择已加载的会话、自定义单行消息、调节发送间隔，以及可选的每日问候计划。没有 Python、浏览器驱动或云端服务依赖。退出 Codex 不影响独立应用运行。

> 当前为 3.1.2 版本。每日计划的日期计算与去重已经自动化测试，真实抖音定时执行尚未完整验收；不保证维持火花，也不保证对方已收到消息。

## 功能

- 分组卡片界面：收件会话、发送计划、消息编辑与运行状态。
- 自定义间隔，最低 0.1 秒，预设 0.1 / 0.2 / 0.5 / 1 秒。默认 0.5 秒。
- 每次 1–100000 次，默认 1 次。目标速率与实际送达速率不同。
- 搜索抖音联系人、翻页加载并累计会话；不会刷新后自动改选第一位联系人。
- 会话标题与输入焦点核对；切换应用或会话时停止正在执行的发送。
- 先核对文字完整写入再按回车，输入框清空后才继续；5 秒写入/清空超时则停止。检测到发送失败或平台限制时停止，不绕过限制、不盲重发。
- 预检模式：只定位会话，不输入、不发送。
- **实验性每日续火花**：北京时间每天指定时间向所选会话发送一条消息。
- 每日计划在尝试前持久化当天记录，同一昵称每天最多自动尝试一次。失败也不自动重试，避免结果不明时重复发送。
- 超过预定时间 15 分钟不补发；日期、消息和间隔保存在本机。

## 使用条件

- macOS 14+，已登录的抖音桌面客户端。
- 首次打开应用，在“连接授权”中允许系统辅助功能权限，用于读取会话、模拟点击和输入。
- 请先在抖音打开消息面板，再点“刷新会话”。点“加载更多”读取后续会话并累计；也可在本工具输入昵称，点“搜索抖音”查询首屏之外的联系人。当前页和累计数量会分别显示。
- 不能仅凭昵称区分同名账户；重复同名条目会被拒绝。请确认当前登录账号和会话，切换账号后应重新刷新并预检。
- 抖音需保持运行。执行发送时会切到前台；应用、电脑和网络需可用。
- 电脑休眠、关机、退出本助手后，不会继续执行。每日计划在重新打开时默认关闭，需手动启用。
- 关闭窗口即退出并取消计划；可最小化窗口保持应用运行。

## 本地构建

安装 Xcode Command Line Tools 后，在仓库目录执行：

```sh
./scripts/test.sh
./scripts/build.sh
open dist/抖音消息助手.app
```

构建脚本按当前电脑架构生成应用与 ZIP，并做本地 ad-hoc 签名；这不是 Apple Developer ID 签名或公证。签名随构建改变时，macOS 可能要求移除旧辅助功能条目，再重新添加更新后的应用。

构建输出位于 `dist/`，不提交到源码仓库。

## 每日续火花

1. 刷新并选中会话，编辑问候文字。
2. 切换到“每日续火花”，选择北京时间。
3. 可先使用“预检（不发送）”。
4. 点击“启用每日续火花”，查看下次执行时间。
5. 点击“停止”取消计划。

这是定时问候功能，不读取或判定真实火花状态。是否保持火花取决于双方互动及平台规则。不同昵称、改名或切换账户后的记录需自行核对；不会上传聊天记录、Cookie 或登录凭证。

## 测试与边界

`Tests/main.swift` 覆盖北京时间换日、下一次执行、闰日、触发窗口、重复尝试、速率边界、搜索昵称片段拼接、UTF-16分段，以及完整写入/回车/清空的发送状态机。测试不发送真实消息。抖音界面更新可能导致定位失败；此时停止并检查，不把界面计数当成送达回执。

## 3.1 修复

新增搜索与分页累计；发送前重新搜索并核对唯一匹配；刷新失败清除旧原生元素缓存。修复发送计数提前增加、占位文字误判、聊天文本误判为平台错误、速率档位不同步、保存的时间参数越界崩溃、每日计划受禁用的重复发送参数阻挡。停止按钮固定在窗口底部；Cmd+Q同样保存设置，休眠中止正在发送的任务。

### 3.1.2 现场修正

“加载更多”改用AXScrollToVisible原生动作，并在搜索时用原生取消按钮恢复列表，避免窗口遮挡与滚轮落点问题。搜索改用系统应用启动服务切换到抖音，随后重新读取搜索框位置；打开搜索结果优先使用原生按钮动作。
